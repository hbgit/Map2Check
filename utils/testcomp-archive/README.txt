Map2Check -- Test-Comp 2027 archive
===================================

Map2Check is a bug-hunting tool for C programs: LLVM passes instrument the
program, and inputs are generated by alternating AFL++ fuzzing with KLEE
symbolic execution, each engine seeded with the other's inputs.

Project: https://github.com/hbgit/Map2Check
License: GPL-2.0 (LICENSE); third-party components under licenses/

Usage (Test-Comp)
-----------------
  ./map2check-testcomp-wrapper.py -p <property.prp> [--data-model ILP32|LP64] \
      [--budget <seconds>] <program.c>

The test suite is written to ./test-suite/ in the current directory, in the
Test-Comp exchange format. Supported properties: coverage-error-call and
coverage-branches. --budget defaults to 900 s; the tool stops shortly before
it so that the suite is complete.

  ./map2check-testcomp-wrapper.py --version   prints the version
  ./smoketest.sh                              runs the two examples in examples/

The archive is self-contained for x86_64 Ubuntu 24.04: it carries LLVM 16
(clang, opt, llvm-link), KLEE 3.1 with klee-uclibc, AFL++ 4.40c and every
shared library they need except glibc; it needs python3 on the host.
The tool can be run from any directory.
